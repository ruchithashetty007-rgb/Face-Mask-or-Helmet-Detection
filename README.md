# Face Mask or Helmet Detection

An AI-powered computer vision system for detecting whether a person is wearing a helmet using deep learning.

## Features

- Helmet detection using a trained deep learning model
- Streamlit-based user interface
- Image-based prediction
- Helmet/no-helmet classification
- Model accuracy visualization
